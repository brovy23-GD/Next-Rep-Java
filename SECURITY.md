# Security Policy

NextRep Java is a local Java 21 learning project and is not a production service.

- Do not commit personal athlete information, credentials, tokens or training logs.
- CSV data under `data/*.csv` is intentionally ignored by Git.
- Text values are Base64 encoded for safe CSV representation, **not encrypted**.
- Run the application using a dedicated local data file.
- Report a security concern privately to the repository maintainer rather than posting sensitive details in an issue.

No security audit, authorization mechanism or network deployment is claimed.
